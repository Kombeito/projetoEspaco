## Onde atualizar mais rápido
### Contatos e redes
Edite:
- `assets/js/site-config.js`

### Imagens
- logo: `assets/img/branding/`
- imagens geradas: `assets/img/generated/`
- novas imagens: `assets/img/uploads/`

### Visual do site
Edite:
- `assets/css/style.css`

### Funcionalidades
Edite:
- `assets/js/main.js`
