# Como atualizar o site do Espaço Gamer

## 1) Contatos e redes sociais
Edite apenas o arquivo `assets/js/site-config.js` para mudar:
- WhatsApp
- e-mail
- Instagram
- cidade/localização

## 2) Imagens
- Coloque novas imagens em `assets/img/uploads/`
- As imagens geradas e a logo já estão em `assets/img/generated/` e `assets/img/branding/`

## 3) Textos e serviços
- Página inicial: `index.html`
- Sobre: `sobre.html`
- Serviços / catálogo: `produtos.html`
- Blog: `blog.html` e arquivos dentro de `blog/`
- Contato: `contato.html`

## 4) Busca de serviços
A busca da página `produtos.html` filtra os cards automaticamente.

## 5) Observação
Os textos foram atualizados com base nas informações enviadas do Instagram `@espac0gamer`.
